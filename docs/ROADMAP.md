# 향후 개발 계획

## v2.4.0 · 커플 기념일

설정에서 두 이름과 시작일을 입력하고 **커플 기념일 표시**를 켜면, 미리보기와 F11 전체 화면의 트리 아래에 기념일을 표시합니다. 기본값은 끔입니다.

```text
[이름] ♥️ [이름]  D+[n일]
```

대괄호는 자릿값을 뜻합니다. 예를 들어 첫날의 실제 출력은 `지우 ♥️ 하늘  D+1일`입니다. 날짜는 PC의 현지 달력을 기준으로 비교하며, 시작일을 첫날로 계산합니다. 시작일이 12월 1일이면 12월 2일에는 `D+2일`입니다.

- 이름과 시작일은 앱의 로컬 설정에 저장합니다. 이름이 비어 있거나 시작일이 미래라면 설정 화면에서 안내하고, 카운터 표시를 보류합니다.
- 켜져 있을 때는 트리 아래 문구 영역에 카운터를 표시합니다. 끄면 기존 개발자 문구가 돌아옵니다. 전체 화면 종료 안내는 계속 표시합니다.
- Windows에서 한글 이름과 하트 글리프, 좁은 창의 잘림, 시작일·다음 날·윤년·자정 경과, 설정 저장과 재실행을 확인합니다.
